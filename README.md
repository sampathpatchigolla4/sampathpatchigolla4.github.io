# Sampath Patchigolla — Personalized Portfolio

Responsive portfolio tailored for **Python Developer / AI & ML / Data Analyst entry-level roles**. The design intentionally uses no profile photo and keeps a clean, professional dark theme.

## Included
- `index.html` — portfolio content
- `style.css` — responsive styling
- `script.js` — mobile navigation
- GitHub profile links: https://github.com/sampathpatchigolla4
- Academic facial-recognition attendance project, clearly marked as not yet published to a public repository

## Before publishing
1. Verify all education dates, marks/CGPA, certification names and dates.
2. Verify the contact email, phone number, and LinkedIn URL in `index.html`.
3. Confirm every skill listed is one you can discuss in an interview.
4. When ready, publish your academic project source code and README to GitHub, then add the repository URL to the project section.

## Publish free with GitHub Pages
1. Sign in to GitHub at https://github.com and create a new **public** repository named `sampathpatchigolla4.github.io` (the username in your supplied profile URL is `sampathpatchigolla4`).
2. Extract this ZIP on your computer.
3. Upload `index.html`, `style.css`, and `script.js` from the `sampath_portfolio` folder to the **root** of the new repository. Do not upload only the ZIP file.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes, then visit `https://sampathpatchigolla4.github.io`. If it does not load yet, check the Pages status in repository Settings.
7. Add the live portfolio URL to LinkedIn's Contact Info / Featured section and Naukri's profile website or portfolio field.

This package contains the website source; it is not live online yet.
